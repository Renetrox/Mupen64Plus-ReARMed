# RiceFZ

Experimental standalone copy of the Rice video plugin from Mupen64Plus FZ (`fzurita/mupen64plus-ae`, branch `fz-master`) for integration into Mupen64Plus-ReARMed as a separate libretro renderer.

This directory intentionally does not replace `gles2rice/`.

Source import and build wiring are being developed on the `ricefz-experimental` branch.
